# 🎥 ProTube YouTube Downloader

A modern YouTube Video and Audio downloader built with Node.js, Express, and FFmpeg.

## ✨ Features
- Download 1080p, 720p, and 480p Videos.
- High-quality Audio (M4A) extraction.
- Professional UI with Glassmorphism effect.
- Real-time loading animation with success notification.

## 🚀 How to Run
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Start the server using `node server.js`.
4. Open `index.html` in your browser.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express
- **Library:** youtube-dl-exec
- **Processing:** FFmpeg
